# Ziad Hesham — Frontend Developer Portfolio

A dark, responsive portfolio built with React, Vite, and Motion. It presents selected frontend projects, technical capabilities, and contact options.

## Stack

- React
- Vite
- JavaScript
- Motion
- CSS
- React Three Fiber in selected project work

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Update portfolio content

- Edit project details in `src/data/projects.js`.
- Add or replace project previews in `public/projects/`.
- Update contact details in `src/data/contact.js` and `src/components/Contact.jsx`.
- Update page metadata in `index.html`.

## Notes

Project checkout and booking experiences are identified as demos where applicable. Do not present demo payment flows as live transactions or add unverified client results, testimonials, or performance metrics.
